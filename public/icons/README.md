# PWA Icons

Place your app icons here with the following sizes:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Quick Generation

You can generate these icons from a single source image using:

```bash
npx pwa-asset-generator your-logo.png ./public/icons --manifest ./public/manifest.json
```

Or use https://realfavicongenerator.net to generate all sizes.

The icon should be a square image with your app logo on a purple (#7c3aed) background.
